# 企业微信群定时通知工具

独立的 Windows 桌面工具。编辑通知、选择企业微信群，设置发送频率、轮次和截止时间，保存启用后自动执行。

## Windows 启动

源码版本需要 Python 3.9 或以上版本。双击本目录的 `run.bat`，首次启动会创建专用 Python 环境并安装 PyQt5 和 requests，需要能够访问 Python 软件源。

已有相应依赖的开发环境可以在项目根目录运行以下命令。

```bash
python -m scheduled_notifier
```

## 生成独立 exe

在 Windows 电脑上双击 `build.bat`，脚本准备依赖并使用 PyInstaller 生成以下文件。

```text
scheduled_notifier\dist\WeComScheduledNotifier.exe
```

目标 Windows 电脑双击 exe 即可启动。Python 环境和打包依赖在构建电脑上准备。

## Windows 安装包

仓库提供 GitHub Actions 的 Windows 自动构建流程。流程运行回归测试、生成独立 exe、编译中文安装程序，并验证安装、启动和卸载。

构建产物 `WeComScheduledNotifier-Setup-1.0.0.exe` 提供中文安装向导、开始菜单、桌面快捷方式和卸载入口。默认安装到当前 Windows 用户的本地应用目录。

本地 Windows 环境可安装 Inno Setup 6.5 或以上版本，先执行 `build.bat`，再使用 Inno Setup 编译本目录的 `installer.iss`。

## 使用步骤

1. 在目标企业微信群中添加群机器人，复制其完整 Webhook 地址。
2. 打开“群组管理”，添加群组名称及 Webhook。也可导入现有通知工具导出的 CSV。
3. 在“通知任务”中新建任务，填写通知内容并选择目标群。
4. 选择固定分钟或小时间隔、每天多个时点，或每周指定星期和时点。
5. 设置开始时间，可勾选总发送轮次和截止时间。
6. 核对下方的未来发送时间，点击“保存并启用”。
7. 在任务列表查看下次发送时间，通过“发送记录”查看逐群结果。

点击“保存为暂停”可以先保存任务，稍后通过“恢复”启用。编辑任务前先暂停并等待当前轮次结束。

## 规则

- 所有计划使用北京时间 UTC+8。
- 一轮表示一个计划时点向各目标群各发送一次。选择五个群，执行一个时点，计为一轮。
- 启动的轮次计入已执行次数，失败重试包含在本轮中。
- 总轮次或截止时间中任意一个先达到时，任务结束。
- 每次发送和重试开始前检查截止时间。截止时间采用严格边界，例如设置 17 点截止，17 点整的计划点按已到期处理。
- 工具运行、电脑开机并联网时执行任务。
- 退出、关机、休眠或暂停期间错过的计划点跳过，恢复后从下一个未来时点继续。
- 同一任务同时执行一轮，下一轮沿原计划计算未来时点。耗时超过间隔时跳过重叠时点。
- 请求超时和连接中断等情况标为“结果未知”，请核对群消息。明确接口失败默认额外重试两次。
- 同一机器人共用每六十秒最多二十次请求的限速。
- 编辑任务保留已执行轮次。已完成或已结束任务可通过新建任务开始新的计数。
- 停用或删除的群在后续轮次中跳过，全部目标无效时任务暂停。
- Markdown 通知最多 4096 个 UTF-8 字节，编辑器显示当前字节数。

关闭窗口时可以选择留在系统托盘中继续运行，或退出并停止任务。工具使用单实例锁避免同一份任务被重复启动执行。

## CSV 导入

使用 UTF-8 或 GB18030 编码，前两列为群名称和 Webhook 地址。兼容现有工具导出的“群名称、Webhook地址、分类、启用”格式，第四列使用“否”“false”或“0”表示停用。

## 本地数据

使用 SQLite 保存任务与逐群结果。点击窗口菜单“打开数据目录”可查看实际位置。在 Windows 上通常位于以下目录。

```text
%LOCALAPPDATA%\RetailTools\WeComScheduledNotifier\
```

目录包含 `tasks.sqlite3`、SQLite 辅助文件、`app.log` 和运行锁文件。更换 exe 后使用同一 Windows 用户启动，会继续读取该用户的数据。

备份前退出工具，复制整个数据目录。界面展示最近 200 轮，完整记录保存在数据库中。

## 开发验证

在项目根目录运行以下命令，使用临时数据库和模拟接口验证。

```bash
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s scheduled_notifier/tests -v
```

Windows 命令提示符中可先设置离屏环境变量，再运行测试。

```bat
set QT_QPA_PLATFORM=offscreen
python -m unittest discover -s scheduled_notifier/tests -v
```
